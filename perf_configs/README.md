# perf_configs/ —— 每台机一份测试参数

一台被测机一个文件:`perf_configs/<型号脚本名>.yaml`(名字和 `models/` 下
那个脚本一模一样)。**在 `start.bat` 里选到这台机,就自动用它的这份**,不用
再复制、改、记住任何别的文件。

没有这个文件也能跑:工具会问你要不要生成一份带注释的模板,你只要把写着
`FILL_ME` 的地方换成台架的真实 IP。

## 里面放什么,不放什么

| 放这里 | 不放这里 |
|---|---|
| 台架**怎么接的**:注入机 IP、对端 IP、每档打谁 | 管理密码、宽带账号 → `router.yaml`(git 忽略) |
| 测什么:哪几档、哪些频段/方向/协议、测多久 | 控件选择器、菜单路径 → `models/<型号>.py` |

所以这些文件**可以进仓库、可以发给同事** —— 它们就是"我们组的台架长这样"
这份共同知识。密码一个字都不在里面。

## 开跑前会自动核一遍

整轮要几十分钟,而且**每一档都会真正切一次路由器**。所以开跑前工具会把参数
逐条核对,`[X]` 会直接拦住,`[!]` 会提醒但照跑,并且把它**实际解析出来的
结果**摊开给你看 —— 尤其是每一档的对端打谁:

```
  dynamic    对端(e2)= 192.168.202.66   <- public_ip (direct)
  v6plus     对端(e2)= 192.168.202.66   <- e2_ip[v6plus] (显式指定)
  pppoe      对端(e2)= 192.168.203.1    <- internet_ip (tunnel)
```

**这一段要用眼睛过一遍。** 检查器能发现"没填",发现不了"填成了另一个真实
存在的 IP" —— 那种错不会报错,只会给你一份打错了口、数字却很正常的报告。

## 优先级

`--config <路径>` > `perf_configs/<型号>.yaml` > `perf.yaml` > 内置默认值

已经配好一个全局 `perf.yaml` 的台架不用动,它继续有效。
