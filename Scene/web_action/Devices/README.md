# Devices/ —— UI 动作单元的交付物放这里

一台设备的一个任务 = 一个目录:

```
Devices/<品牌>_<型号>/<任务名>/
    action.py      这个动作本身,可以单独跑
    facts.yaml     任务表 + 找到的控件位置(带注释说明怎么确认的)
    tools/         可选:从 Tools/ 复制过来、按这台机改过的探针
```

现在是空的 —— **样板等真机**。手上没有能访问的设备时,照着抄一份"看起来
对"的脚本,只会让下一个人以为它验过。真机上跑通了再往这里放。

怎么做一个:读 `../SKILL.md`(任务表)和 `../../../Tools/probing.md`
(技术细则,含产出契约)。

工具本身有没有坏,不用等真机 —— `python tests/mock_test.py` 拿假设备页
跑一遍就知道。
