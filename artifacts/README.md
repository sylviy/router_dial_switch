# artifacts/ —— 跑动产生的东西都落在这里

**这个目录的内容不进仓库**(`.gitignore` 里整个忽略,只留目录本身)。
出争议时翻它;要回传给别人之前先看一眼有没有账号密码。

| 子目录 | 放什么 | 谁写的 |
|---|---|---|
| `reports/` | 整轮的 HTML + CSV 报告,以及那一轮的 Chariot `.tst` 原始记录(`wanperf_<型号>_<时间戳>_tst/`) | `common/perf.py` |
| `shots/` | 每次切档的整页截图 `model_<型号>_<档>.png` —— **失败时也会有**,排查先看它 | `models/<型号>.py` |
| `probes/` | 适配新机型时的产物:控件清单 `probe_<地址>.json`、试切截图 `try_switch_<被测机地址>_<措辞>.png` | `skill/tools/` |

文件名里带时间戳的(报告)不会互相覆盖;不带的(截图、控件清单)是**同一台
机同一档只留最新一次**,那是有意的 —— 排查时要看的就是最近那次。
